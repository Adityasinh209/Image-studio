# Smart Image Studio

An all-in-one image optimization tool built with Next.js 16, React 19, Tailwind CSS v4, and shadcn/ui.

## Features

- Image upload (JPG, JPEG, PNG, WEBP)
- Resize by width, height, or percentage scale
- Brightness, contrast, sharpness, and noise reduction controls
- One-click auto enhancement
- Social media presets (Instagram, Facebook, LinkedIn, YouTube, X)
- Before/after comparison slider
- Export to PNG, JPG, or WEBP

## Tech Stack

- Next.js 16.2 (App Router, Turbopack)
- React 19
- TypeScript 6
- Tailwind CSS v4
- shadcn/ui
- Sharp (server-side export)

## Getting Started

Requires Node.js 24 LTS.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — run ESLint
